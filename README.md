=== Description ===

A cookie clicker clone on generating bits every bit has a chance to be 1 or 0 expand the Bits and earning more Bits. Once enough Bits are gathered Rebirth to start over again but with a bigger multiplier.

=== How To Run ===

Click this link to play --> https://inf-clicker.vercel.app/

=== Frameworks Used ===
Used Vercel to deploy
Used Vite to create a react project
Used React with TypeScript for the website
